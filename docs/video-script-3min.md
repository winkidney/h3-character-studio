## 对应段落的口播草案

01：先看效果。青绿少女在夜晚街道慢步，移动速度和动画时钟一起调整。

02：接下来是四向光照。角色留在暗处持续侧面走动，白光依次从上、下、左、右照射，每个方向停留六秒，动画按正常速度播放。左栏看原色与银饰，右栏用灰材质观察形体。

03：再看冷光、暖光和混合光，每轮十二秒。光源先扫过正面，再从一端经头顶返回另一端。机位和角色位置固定，腰饰高光由镜面反射随灯位变化。

04：现在回到制作过程。最初的青绿行旅少女保留服装结构，增加银饰，把单辫改成双马尾。角色设计先确定，再扩展方向和动作。

05：四个方向分别生成。皮包固定在角色右胯，包带斜过身体；背面只描述后脑、披肩和后裙。母版统一到七百六十八画幅，保持角色高度和脚底锚点。

06：本次实验使用 Linux、Python 三点一二、CUDA 十三点零和 RTX 四零七零 SUPER。项目需要 Git、FFmpeg、PyTorch、独立 ComfyUI，以及列出的 Python 依赖和 H3、ToonOut 模型。安装依赖，参考项目文档。

本节引用：[项目文档：安装、模型与环境](https://github.com/winkidney/h3-character-studio/blob/main/docs/runbooks/01-install.md)。视频只显示环境、依赖和文档地址，不展开安装命令。

07：H3 从方向母版和提示词生成五十六帧，二十四帧每秒、四十步。提交一次后保存原作业，恢复查询继续追踪；全部帧仍需检查身份、方向和循环。

08：背面首轮转成正面，第二轮双脚交替不自然。第三轮调整引导与动作描述；方向保持和前后脚交替分别审查。

09：ToonOut 提取保留十六位软 alpha 和恢复后的前景 RGB。量化前检查背景杂色，再映射共享九十六色板。选择连续原帧二十八至五十四，共二十七帧。

10：头发、披肩、手臂、裙褶和鞋子分别标注形体。脸部和银饰使用逐帧像素归属，绑定源图摘要；颜色、法线、材料图集使用同一帧和锚点，最后检查实际灰材质受光。

11：受光不充分时，先检查形体覆盖和局部朝向。减弱整块鼓包，区分肢体、发束与衣褶；布纹亮度不直接变成高度。

12：背景杂色可能被调色板变成棕黑色，掩盖抠图错误。我们重做前景与脸颈归属，删除鼻部法线块，再用无损 GPU 原帧复核。

13：提示词和完整制作步骤见独立项目与 runbook。

## 录制与剪辑来源

四向新增镜头在隔离 Godot 副本的两个独立世界中渲染，原色／灰材质共享相同动画帧、相机与灯位。关闭环境光、天空反射和场景几何，仅使用单一白色点光。四个相对灯位在可见半球内，避免背面照射造成正面全黑；每次切换用 0.8 秒平滑过渡，随后固定观察。

所有游戏片段保留 PNG 或 RGB 无损来源，标题、文字和进度条在 RGB 中合成，MP4 作为播放副本。离线 30FPS 录制不作为实时性能证明。旧 v8 影片保留，新剪辑位于 `output/video-technical-v9-review/`；可编辑参数与脚本见 `examples/video/`。

三份专题：[衣物法线](topics/clothing-normals.md)、[银饰镜面反馈](topics/silver-specular-feedback.md)、[外部块与像素归属](topics/foreground-and-material-ownership.md)。本轮修订仍在本地，尚未推送到公开仓库。

四向 v12 读取用户在交互界面保存的参数：点光 2.65、环境光 0、法线 0.8、正面距离 0.8 米、左右幅度 1.7 米、上下幅度 1.6 米、范围 7.6 米。用户随后要求正常行走，录像明确覆盖播放倍率为 1.0，保留原保存值与覆盖记录。界面只用于固定帧比较，正式四向录像不暂停。

## 本轮屏幕标记与素材来源

概念设计与四方向母版均显示“需要 GPT Image 或本地 Qwen 2.1 等生图模型”。本次实际来源仍标为 ImageGen；Qwen 是用户指定的替代模型标签，不代表本次已经用它生成。

从背面失败至片尾汇总，统一显示副标题“踩坑记录”。正文分别列“失败环节”和“纠正环节”，保留方向生成、前景提取、法线体积、金属像素归属及 GPU 复核的边界。

同姿态素材页在每张图下独立说明：颜色提供服装、肤色和纹理，来自 H3 与 ToonOut，母版来自 ImageGen；法线提供表面方向，用于动态明暗与体积，来自几何重绘和光流运输，ImageGen 灰材质图只作辅助参考；金属蒙版限定银饰镜面反射，白色金属、黑色非金属，来自逐帧像素归属标注。不能把灰材质参考图或颜色帧当成直接生成的法线。

片尾保持原有 4 秒，176.4 秒开始显示“觉得有用记得一键三连喔”。像素文字弹入，随后“点赞”“投币”“收藏”依次亮起，无配音或新增音乐，全片保持 180 秒。

# 银饰有蒙版，为什么镜面高光仍不明显

这是衣物法线专题之后的材质讲解小节。银饰少女的月牙面积大，曲面法线能形成一段移动高光。青绿少女的银饰分散，不能仅靠更亮的灯得到同样清晰的反馈。

## 本次定位

同一右侧第11帧，原红色角色金属覆盖698个源像素，最大的月牙连通区域166像素；新角色覆盖143像素，胸针最大区域29像素。面积不同是设计差异，不能为了匹配面积把玉叶或衣纹涂成金属。

旧shader用银饰响应0.75混合布料与金属参数，实际粗糙度约0.40、金属度0.585。虽然蒙版和逐帧法线都已存在，反射仍偏散。强光还能让浅色衣物过亮，压低银饰高光的视觉对比。

## 修订

保留原颜色帧、逐帧法线、金属蒙版和衣物参数，仅在银饰区域使用粗糙度0.12、金属度0.95、SPECULAR参数1.0。使用Godot native GGX反射，不添加自发光，也不往颜色帧画白斑。SPECULAR是引擎材质输入，不应当解释为金属总反射能量。

单灯能量从3.5降至1.8，混合阶段每灯0.9。保持原正面竖直椭圆、机位和慢步时钟：冷、暖、混合各12秒，夜晚暗处持续侧面原地走动。发圈、胸针、腰饰与腕环的高光由光源方向和该帧法线共同决定，不能整片饰品恒亮。

适配片段见`examples/godot/polished-silver.gdshaderinc`。在现有fragment()的普通材质参数赋值后应用返回值：

```glsl
vec3 silver_brdf = polished_silver_brdf(silver, ROUGHNESS, METALLIC, SPECULAR);
ROUGHNESS = silver_brdf.x;
METALLIC = silver_brdf.y;
SPECULAR = silver_brdf.z;
```

材质设置`polished_silver=1.0`启用，设0恢复旧参数。默认关闭，避免改变已有角色。蒙版采样仍为线性，法线不声明source_color。此片段需要已有spatial shader与native GGX渲染模式；不是可直接挂载的完整shader。

## 验证和拍摄

先固定右侧第11帧，用48个灯位逐个采集旧参数与新参数的同姿态GPU画面，只切换polished_silver。再独立录制两个36秒原地步行版本，核对1080个时刻的方向、帧索引、时钟、机位和灯位均一致。

截图提供同灯位前后对照，以及新材质在不同灯位的反馈。局部放大采用最近邻裁切，只用于看清小饰品，不改变颜色。完整视频保留全身和局部观察窗，标明离线电影输出，不据此宣称实时性能。

美术目标是可见、随灯位移动的镜面亮带，不是让更多像素饱和变白。新角色饰品面积较小，亮带长度与月牙不同，最终观看审查仍独立于数值校验。

## 暂拟口播

法线和金属蒙版配对正确之后，还要检查反射材质。原来的银饰粗糙度混合到约0.40，亮光散开；再提高灯强，会先把浅色衣服照亮。我们只给银饰换成更光滑的反射参数，并降低灯强。现在看腰饰和胸针，高光随灯移动掠过，而颜色帧没有新增白斑。


## 后续修订：小像素银饰不能只追求低粗糙度

腰饰试用0.09粗糙度时，亮点过窄，部分角度比0.12版本更暗。这是粗糙度、离散法线采样和饰品尺寸共同造成的观察问题，不能用“更低一定更亮”解释。最新腰饰单独用0.18粗糙度形成更宽的反射范围，并将80%的腰饰材质ALBEDO混合到线性银反射率[0.80,0.82,0.85]。原图上的绘制阴影不应直接当作银材质的F0。其他银饰仍为0.12，金属度0.95，仍无自发光。

这是shader中的银材质反射率调整，源颜色PNG没有改动；不能宣称材质ALBEDO完全不变。腰饰响应区必须与最终银饰蒙版相交。使用`examples/jade-traveler/build_material_response.py`生成逐帧语义响应图集，R为头发、G为衣物、B为腰饰银，Alpha沿用原帧。`examples/godot/waist-silver.gdshaderinc`提供补充材质函数。

最新光路分两段：前6秒从右端沿低位正面弧线到左端；后6秒从左端升至头顶上方3米，再回到右端。高度在端点1米、低位最低0.25米，所有灯位仍保持正面z=1.3米。冷、暖、混合各12秒，混合两灯相差半周期。端点位置和速度连续，避免拍到背面或极暗侧边。

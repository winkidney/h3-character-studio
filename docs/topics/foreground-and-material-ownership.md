# 外部块不是下巴形变：前景、法线与材质归属的联合检查

## 本次症状

暖光段从约 12 秒开始，下巴附近偶尔出现突出的外部块；鼻子存在独立法线小块。用户接受少量自然的下巴变化，要求排除突然出现的额外像素和错误受光区域。本次保留 H3 原始动画，不重新生成、不用刚性下巴轮廓误差决定是否合格。

## 已确认的问题

1. ToonOut 抠图确实运行过，但神经蒙版仍把发丝、脸颈之间的部分洋红背景认成前景。前景 RGB 恢复不能自动修正错误的 alpha。随后共享调色板把杂色变成棕黑色，导致“最终 PNG 没有洋红色”的检查假通过。
2. 肤色凸包扩展脸部表面，把颈部和衣领纳入脸部法线；米白披肩也会通过简单肤色阈值。法线必须服从逐帧可见部位归属，不能用颜色凸包当解剖边界。
3. 鼻子小椭球按脸部包围盒估算位置，而非真实鼻部像素。已删除这条生成规则和本次候选中的 `nose-volume`；脸部采用受逐帧像素约束的缓和表面。
4. 中性色连通岛不能证明是银饰。旧的 `silver-island-*` 提案被移除。银饰由逐帧命名饰品的确切像素标注决定，不能覆盖保护的皮肤，也不能越过颜色 alpha。
5. 旧录制先输出有损 MJPEG，再从有损视频放大画面、再次压缩；这会混合边缘色。修正版应从 Godot PNG 原帧制作局部放大，保存 RGB 无损母版，再输出播放副本。

## 修复与验收机制

- 保留原始神经 soft mask；先验证画布边界是均匀洋红背景，再融合背景先验。非洋红背景继续使用神经抠图，不套用洋红规则。
- 角色调色板与背景色相碰撞时停止处理，不能直接删除角色颜色。使用原始合成关系 `C = alpha * F + (1-alpha) * B` 和共享调色板恢复边缘；不对整圈轮廓统一腐蚀。
- 在调色板映射前检查原始背景与恢复 RGB。记录需要视觉复核的边缘恢复像素；数值检查为必要条件，不能替代黑、白背景下的逐帧审查。
- 每帧材料标注绑定源 PNG SHA256 与帧序号，初始状态是 `proposal`。视觉检查后才成为 `agent-reviewed`，最终美术确认仍是 `pending`。不同饰品不可拥有同一像素；透明背景、受保护身体区域和未知饰品均拒绝。
- 脸部同样需要逐帧 `surface_regions`，不允许旧皮肤凸包扩大区域。蒙版改变后重新绘制稀疏法线层，不能复用覆盖范围已经过期的旧层。
- 使用正常颜色、禁用法线、禁用金属、clay 和新旧同光照对照定位来源。核对帧序、alpha、法线、银饰及腰饰反射区域的一致性。
- 不因微小自然轮廓变化重生成动画。只有原始 H3 帧本身出现明显额外体块，且后处理无法可靠修复时，才讨论重生成。

## 视频讲解重点

“抠图执行过”不等于“抠图正确”。调色板可能掩盖杂色，却不能移除错误的前景像素。法线和金属材质还会进一步放大错误归属。先检查前景，再检查身体和饰品逐帧归属，最后检查无损 GPU 原帧和视频编码，才能解释外部块来自哪里。
